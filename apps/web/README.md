# pr-crew web

React + Vite frontend for pr-crew: submit a GitHub PR URL and watch the agent crew review it live over SSE.

- `npm run dev` starts the dev server; point it at a backend with `VITE_API_BASE_URL` (defaults to `http://localhost:8000`).
- `npm test`, `npm run lint`, and `npx tsc -b --noEmit` mirror CI.

See the [root README](../../README.md) for the full project.
